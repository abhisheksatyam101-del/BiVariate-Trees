Bivariate Decision Trees: Smaller, Interpretable, More Accurate

B.Tech Computer Science & Engineering — Seminar Project Report

Base Research Paper: Bivariate Decision Trees: Smaller, Interpretable, More Accurate

Authors: Rasul Kairgeldin and Miguel A. Carreira-Perpinan

Conference: ACM SIGKDD 2024

Implementation: Pure Python Implementation from Scratch (CART, BiCART, BiTAO)

Dataset: UCI Breast Cancer Wisconsin (Diagnostic)

Abstract

Decision trees are among the most valued machine learning models due to their conditional computation and high human interpretability. However, standard univariate decision trees such as CART are limited by axis-parallel splits, which can produce stair-step decision boundaries and large trees when features are correlated or when class structure is tilted.

This project presents a complete implementation and empirical analysis of bivariate decision trees introduced by Kairgeldin and Carreira-Perpinan. Bivariate splits use at most two features and a linear decision rule of the form w1 x_i + w2 x_j + b < 0, enabling a tilted 2D decision boundary rather than an axis-aligned split. The study evaluates both BiCART and BiTAO on the UCI Breast Cancer Wisconsin dataset.

Empirical results show that BiCART achieves 97.37% test accuracy, outperforming standard CART by 6.14%, while reducing total tree nodes by 54%. BiTAO further compresses the model to only three nodes and two unique features, providing maximum interpretability with a compact structure. These findings demonstrate the practical value of bivariate splits for both performance and transparency in tabular classification.

1. Introduction & Motivation

Decision trees process instances along a single root-to-leaf path and provide fast inference and clear rule-based explanations. Yet standard univariate trees rely on axis-parallel cuts, which often produce long and overly complex trees when the true decision boundary is diagonal, curved, or otherwise oriented in feature space.

Bivariate decision trees address this limitation by allowing each split to depend on at most two features. This creates a tilted 2D boundary that captures structure more compactly and better matches correlated features. Instead of many staircase-like splits, the tree can separate classes with a small number of linear oblique decisions.

  • Poor Data Modeling: Axis-aligned splits struggle to approximate simple tilted hyperplanes.
  • Complexity of Oblique Trees: Dense oblique splits can become hard to interpret and difficult for domain experts to analyze.
  • Interpretability: When only two features are used per split, the decision boundary can be visualized directly as a line in a 2D scatter plot.

2. Theoretical Background

A bivariate decision node selects a feature pair (i, j) and parameters (w1, w2, b), with the rule:

If w1 x_i + w2 x_j + b < 0, go LEFT; otherwise go RIGHT.

By normalizing the normal vector, the split can be written as a 1D projection:

z_n = x_{n,j} cos(theta) - x_{n,i} sin(theta) <= rho

where theta defines the orientation of the split and rho defines the offset along the rotated axis. This efficiently transforms a 2D decision boundary into a simple thresholding problem after projection.

3. Algorithms Evaluated

BiCART

BiCART is a fast greedy, top-down algorithm that extends CART by evaluating all univariate thresholds and all bivariate candidate splits over feature pairs and discretized orientations. It chooses the split with minimum weighted Gini impurity.

BiTAO

BiTAO optimizes a fixed tree structure by alternating updates across nodes. It uses pseudolabel assignments and evaluates candidate solutions for each node: bivariate, univariate, or zero-variate. This yields monotonic convergence of the global objective and often a much smaller, sparser tree.

4. Experimental Setup

The UCI Breast Cancer Wisconsin dataset contains 569 tumor samples, each described by 30 numeric real-valued features. The data were split into 455 training and 114 test samples. All features were standardized prior to model fitting.

  • Classes: Benign and Malignant
  • Preprocessing: Standard scaling (mean 0, variance 1)
  • Evaluation: Accuracy, macro F1, macro precision, macro recall, node count, depth, and feature usage

BiCART produced the best overall predictive performance, while BiTAO yielded the most compact and interpretable model. BiCART achieved a 6.14% absolute gain in accuracy over standard CART, while reducing total node count by 54%. BiTAO reduced the structure by over 90%, using only 2 unique features and only 3 total nodes.

6. Key Findings

  • Higher Accuracy: Bivariate splits significantly outperform axis-parallel decision boundaries on this dataset.
  • Compact Trees: BiTAO produces much smaller trees with fewer leaves and lower depth.
  • Interpretability: 2D decision boundaries can be visualized directly in the plane of two important features.
  • Practical Value: The method is especially promising for medical and high-stakes applications where transparency matters.

7. Conclusion

Bivariate decision trees provide a meaningful middle ground between standard CART and dense oblique trees. They achieve stronger predictive accuracy, smaller structures, and better interpretability. In this study, the implementation confirms the core claim of the paper: bivariate splits can improve both performance and transparency without sacrificing the intuitive nature of decision trees.
